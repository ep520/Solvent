Trigger API

A tiny local test endpoint. Your application reports a trigger when it detects something questionable in a call; the list page shows all reported triggers. Open the list.

Endpoints

MethodPathWhat it does
POST/triggersReport a trigger. JSON body, see below. Answers 201 with the stored trigger.
GET/triggersAll triggers. JSON for clients; a browser gets the list page, where a click on a title opens its link in a new tab. Force one with ?format=json or ?format=html.
DELETE/triggersClear the list (handy between test runs). Answers 204.

Body of POST /triggers

FieldRequiredMeaning
urlyesAbsolute http or https link back into your product, ideally straight to the suspicious passage (for example with about 10 seconds of audio before and after).
titleyesShort label shown in the list, up to 200 characters.
descriptionnoWhy this was flagged, up to 2000 characters.

A missing or invalid field answers 400 with an error message and an example body.

Response

{
  "id": 1,
  "url": "https://example.com/calls/42?t=95",
  "title": "Possible insider trading",
  "description": "Customer wants to buy before the announcement.",
  "created_at": "2026-10-09T18:30:00+00:00"
}

Examples

The examples use the address this page was opened from.

curl (macOS, Linux, Git Bash)

curl -X POST BASE/triggers \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/calls/42?t=95", "title": "Possible insider trading", "description": "Customer wants to buy before the announcement."}'

curl BASE/triggers

PowerShell (Windows)

$body = @{
  url = "https://example.com/calls/42?t=95"
  title = "Possible insider trading"
  description = "Customer wants to buy before the announcement."
} | ConvertTo-Json

Invoke-RestMethod -Method Post -Uri "BASE/triggers" -ContentType "application/json" -Body $body
Invoke-RestMethod -Uri "BASE/triggers"

Python

import requests

trigger = {
    "url": "https://example.com/calls/42?t=95",
    "title": "Possible insider trading",
    "description": "Customer wants to buy before the announcement.",  # optional
}
response = requests.post("BASE/triggers", json=trigger, timeout=5)
response.raise_for_status()
print(response.json())

print(requests.get("BASE/triggers", timeout=5).json())

Java (11+)

String json = """
    {"url": "https://example.com/calls/42?t=95",
     "title": "Possible insider trading",
     "description": "Customer wants to buy before the announcement."}""";
HttpRequest request = HttpRequest.newBuilder(URI.create("BASE/triggers"))
    .header("Content-Type", "application/json")
    .POST(HttpRequest.BodyPublishers.ofString(json))
    .build();
HttpResponse<String> response = HttpClient.newHttpClient()
    .send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.statusCode() + " " + response.body());

C# (.NET 6+)

using System.Net.Http.Json;

using var client = new HttpClient();
var response = await client.PostAsJsonAsync("BASE/triggers", new {
    url = "https://example.com/calls/42?t=95",
    title = "Possible insider trading",
    description = "Customer wants to buy before the announcement."
});
response.EnsureSuccessStatusCode();
Console.WriteLine(await response.Content.ReadAsStringAsync());

Notes

  • Cross-origin requests are allowed, so a browser front end on another port can call the API directly.
  • From inside another Docker container, reach the API on the host with http://host.docker.internal:PORT (on Linux add --add-host=host.docker.internal:host-gateway), or put both containers on one Docker network.
  • The list lives in memory and is empty after a restart, unless DATA_FILE is set.
